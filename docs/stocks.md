# 个人股票交易

## ⚠️ 重要：功能模块规则

### 固定模块结构（不可轻易修改）
1. **📊 仪表盘** - 今日选股、持仓概览、收益率、提醒
2. **🔍 选股** - 根据条件筛选股票
3. **💼 持仓** - 添加/删除持仓、设置止损
4. **📈 分析** - 输入股票代码，分析是否符合策略

### 交流规则
- 模块增删 → Boss决定
- 模块内功能 → Boss告诉我具体需求
- 我可建议，但最终Boss决定
- **不要轻易改变模块结构**

## 选股条件一

| 条件 | 说明 |
|------|------|
| 90%筹码集中度上移 | 顶部集中 |
| 昨日振幅小于5% | 波动小 |
| 70%筹码集中度上移 | 底部集中 |
| 去掉ST股 | 风险排除 |
| 市值大于50亿 | 大盘股 |
| 最近10个交易日涨停过 | 有涨停基因 |
| 90%筹码集中度 11%-15% | 集中区间 |
| 70%筹码集中度 4%-10% | 集中区间 |
| 板块强弱排序 | 板块涨停家数≥1 |
| CCI上移 | 趋势向上 |

## 涨停股二次筛选

| 条件 | 说明 |
|------|------|
| 第二天放量上涨 | 资金接力 |
| 没有长上影线 | 卖压轻 |
| 回调准备进攻二波 | 形态支撑 |
| 短期压力位 | 阻力分析 |
| 短期支撑位 | 防守分析 |
| 未跌破支撑位 | 趋势未坏 |

## 重要指标：知行短期趋势线

```
EMA(EMA(C,10),10)
```

```
知行短期趋势线: EMA(EMA(C,10),10),COLORFFFFFF,LINETHICK1
知行多空线: (MA(CLOSE,M1)+MA(CLOSE,M2)+MA(CLOSE,M3)+MA(CLOSE,M4))/4
```

**判断方法：** 不破短期趋势线为强势
