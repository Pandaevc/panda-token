# PandaToken 项目总结

## 核心参数

| 参数 | 数值 |
|------|------|
| 代币总量 | 60亿 PANDA |
| 挖矿池 | 40亿 (66.7%) |
| 基金会 | 10亿 (16.7%) |
| 底池 | 10亿 (16.7%) |

## 销毁机制

- 转账手续费: 0.5%
- 50%销毁, 50%给owner

## Turbo (合约实现)

| 模式 | 手续费 | 释放 |
|------|---------|------|
| 直接 | 20% | 即时 |
| 30天 | 10% | 线性 |
| 60天 | 0% | 线性 |

## 合约列表

1. PandaTokenV2.sol - 代币合约
2. PandaExchangeV2.sol - 交易所
3. PandaTurbo.sol - Turbo释放
