# 红熵AI股票管理系统

## 系统概述

**红熵AI股票管理系统** - 基于3天波段量化策略的智能股票分析工具

---

## 三大核心功能

### 📊 功能一：每日精选（3天波段策略）

**定位**：每日早上9点自动推荐，符合Boss最终版量化策略

**选股条件（11条）**：

| 条件 | 说明 |
|------|------|
| ST过滤 | 剔除ST、*ST、退市股 |
| 市值 | 总市值 > 50亿 |
| 10日涨停 | 最近10个交易日有过涨停 |
| 振幅 | 昨日振幅 < 5% |
| 缩量 | 近5日成交量温和缩量 |
| 换手下降 | 近5日换手率逐步下降（主力锁仓） |
| 均线 | 股价在5日均线与10日均线上方 |
| CCI | CCI指标趋势上移 |
| 板块 | 所属板块涨停家数 ≥ 1 |
| 换手率 | 近20日平均换手率 ≤ 8% |
| 筹码 | 近期无巨量出货阴线 |

**评分系统**：

| 指标 | 分数 |
|------|------|
| 振幅 < 5% | +15分 |
| 站上5日+10日均线 | +20分 |
| 缩量 | +15分 |
| 无巨量阴线 | +10分 |
| 10日涨停 | +10分 |

**选股门槛**：≥50分

**回测数据**：

| 指标 | 数值 |
|------|------|
| 股票池 | 1000只 |
| 交易次数 | 5255次 |
| 3天胜率 | **48.2%** |
| 平均收益 | +0.44%/天 |
| 总收益 | **+2336%** |
| 5%以上 | 10.7% |
| 10%以上 | 3.9% |

---

### 💼 功能二：持仓诊断

**功能**：对现有持仓股票进行诊断，给出操作建议

**诊断规则**：

#### 减仓信号（减仓50%）
- ✅ 盈利 ≥ 8%
- ✅ 跌破5日均线

#### 清仓信号（全部卖出）
- ❌ 亏损 ≥ 5%（止损）
- ❌ 盈利 ≥ 15%（止盈）
- ❌ 跌破20日均线
- ❌ 单日放量大跌超6%
- ❌ 持有时间超过7天

#### 持仓原则
- 🚫 不加仓
- 🚫 不补仓
- 🚫 不摊薄成本

---

### 📈 功能三：个股深度分析

**功能**：输入任意股票代码，获取全面分析

**分析维度**：

1. **技术面**
   - 均线形态（站上5日/10日/20日）
   - 成交量健康度
   - 趋势判断

2. **资金面**
   - 换手率
   - 量价关系
   - 主力动向

3. **基本面**
   - 市值
   - 所属行业
   - 涨停基因

4. **风险评估**
   - 支撑位/压力位
   - 止损建议
   - 止盈目标

**评分标准**：

| 级别 | 分数 | 建议 |
|------|------|------|
| 强烈推荐 | 80+ | 买入 |
| 推荐 | 60-79 | 关注 |
| 中性 | 40-59 | 观望 |
| 不推荐 | <40 | 回避 |
