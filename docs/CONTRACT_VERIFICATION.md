## 验证步骤

### 第一步：注册/登录 TRONSCAN

1. 打开 https://tronscan.org
2. 点击右上角 "Login"
3. 选择登录方式（推荐用 Google 账号）

### 第二步：提交代币信息

登录后，点击 "Submit Token" 或访问：
https://tronscan.org/#/submit/token

### 第三步：填写表单

| 字段 | 填写内容 |
|------|----------|
| Token Name | PandaToken |
| Token Symbol | PANDA |
| Total Supply | 4000000000000000000000000000 (40亿 × 10^18) |
| Decimals | 18 |
| Contract Address | TMuA5bn29rMnYGF6xXU2s2u2q7MMPfKfX |
| Price | 0.005 |
| Description | 只涨不跌代币，电子烟挖矿 |
| Website | (你的网站) |
| Icon | 上传 logo.png |

### 第四步：提交

提交后等待审核（通常1-24小时）
