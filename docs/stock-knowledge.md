# 股票知识学习笔记

## 1. CCI指标 (顺势指标)

### 计算公式
```
TP = (最高价 + 最低价 + 收盘价) / 3
SMA(TP) = TP的N日简单移动平均
MD = TP与SMA的绝对偏差的N日平均
CCI = (TP - SMA) / (0.015 * MD)
```

### 解读
- CCI > 100: 超买，可能回调
- CCI < -100: 超卖，可能反弹
- CCI上移: 上涨趋势
- CCI下移: 下跌趋势

## 2. 筹码集中度

### 计算方法
- 90%筹码集中度: 90%的筹码集中在哪个价格区间
- 70%筹码集中度: 70%的筹码集中在哪个价格区间

### 判断标准
- 集中度11-15%: 高度集中 (优质)
- 集中度4-10%: 中等集中
- 集中度<4%: 筹码分散

### 集中度上移
- 筹码向更高价位移动
- 说明主力建仓
- 后市看涨

## 3. 资金流向

### 资金分类
- 超大单: >100万股或1000万元
- 大单: 10-100万股
- 中单: 1-10万股
- 小单: <1万股

### 主力净流入
= 超大单净流入 + 大单净流入

### 解读
- 主力净流入 > 0: 主力买入
- 连续3天主力净流入: 强烈信号
- 主力净流出: 主力出货
